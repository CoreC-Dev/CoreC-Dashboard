# CoreC-Dashboard Architecture & Performance Optimization Plan

> Generated by multi-agent analysis (architecture, performance, UX/responsive, code-slimming).
> Baseline: build ✓ (457ms), 339 tests ✓, ~26k LOC across 114 source files.

## 1. Architecture Problems

### 1.1 [CRITICAL] Detail pages PUT partial config → data loss
**Files:** `DriverDetailPage.tsx`, `TransportDetailPage.tsx`
**Root cause:** `buildDriverYaml`/`buildTransportYaml` create a single-entity YAML doc and PUT it directly. CoreC backend `Reload()` does full-replace — wipes all other config sections.
**Fix:** Merge edited entity into full parsed config via `upsertDriver`/`upsertTransport` before PUT. Keep single-entity preview for readability.
**Status:** ✅ FIXED & verified (build ✓, 339 tests ✓)

### 1.2 [HIGH] God-components (ConfigCenterPage 1015L, TagExplorerPage 997L, RulesPage 944L, AppShell 565L)
**Fix:** Decompose by concern (deferred — high risk, low immediate ROI).

### 1.3 [HIGH] Apply-config boilerplate duplicated across 4 pages
**Fix:** Extract `useConfigApply()` hook (deferred — works correctly, just repetitive).

### 1.4 [HIGH] Field metadata triple-sourced (settingsRegistry, configSchema, detail pages)
**Fix:** Make settingsRegistry the single source of truth (deferred — large refactor).

### 1.5 [HIGH] No `useWebSocket` hook — 5 components hand-roll WS lifecycle
**Fix:** Add `useWebSocket<T>()` hook (deferred).

### 1.6 [MEDIUM] configStore global singleton, not scoped per instance
### 1.7 [MEDIUM] configStore hand-wraps 5 entity types with identical CRUD boilerplate
### 1.8 [MEDIUM] `any` types at data boundary (DataPoint.value, WriteCommand.value)
### 1.9 [MEDIUM] instanceStore re-declares EngineStats shape inline
### 1.10 [MEDIUM] AppShell eagerly imported into every route chunk
### 1.11 [LOW] Module-scope side effects in themeStore/i18n
### 1.12 [LOW] fallbackLng is zh-CN (should be en)
### 1.13 [LOW] Duplicated layout-route wrapper for monitor/admin
### 1.14 [LOW] Polling intervals hardcoded in hooks

## 2. Performance Problems

### 2.1 [HIGH] TagExplorerPage filter+sort cascades at 60×/sec via rAF
**Files:** `TagExplorerPage.tsx:450,472-496`
**Fix:** Add `useDeferredValue` for the filter input so the expensive `filteredTags` memo doesn't block every keystroke.

### 2.2 [HIGH] RulesPage rule list not virtualized (944 lines, renders all rules)
**Fix:** Add `useVirtualizer` (deferred — complex, current rule counts are small).

### 2.3 [MEDIUM] AppShell progress bar animates `width` (layout thrash, 4 re-renders)
**Fix:** Replace with CSS `transform: scaleX()` + `transform-origin: left` (composited, no layout).

### 2.4 [MEDIUM] `useIsMobile` re-renders on every resize tick
**Fix:** Use `window.matchMedia('(max-width: 767px)')` — only fires at boundary crossing.

### 2.5 [MEDIUM] Non-composited infinite glow animation (box-shadow)
**Fix:** Replace `box-shadow` glow with `opacity`/`transform: scale` on `::after` pseudo-element.

### 2.6 [MEDIUM] Admin pages over-poll at 5s interval
**Fix:** Increase admin hook `refetchInterval` to 15s (drivers/transports/rules).

### 2.7 [LOW] card-stagger only staggers first 8 children
**Fix:** Use inline `style={{ animationDelay }}` in map.

## 3. UX / Interaction Problems

### 3.1 [HIGH] Mobile drawer touch targets below 44px (h-9=36px)
**Fix:** Bump to `h-11` (44px), hamburger to `w-11 h-11`, close button to `w-9 h-9`.

### 3.2 [HIGH] Mobile topbar shows only hamburger — no brand/title/status
**Fix:** Add logo + page title + connection-status dot to mobile header.

### 3.3 [HIGH] Realtime indicator pill overlaps greeting on mobile
**Fix:** Compact dot-only form on mobile, absolute pill on `md:` and up.

### 3.4 [HIGH] DriverDetailDialog tag table clips on mobile (overflow-hidden)
**Fix:** Change wrapper to `overflow-x-auto`.

### 3.5 [HIGH] Missing error states on DriversPage, TransportsPage, AlertsPage, ConfigCenterPage
**Fix:** Add `isError` branch with AlertCircle + Retry button.

### 3.6 [HIGH] Icon-only buttons rely on `title` instead of `aria-label`
**Fix:** Add `aria-label` to every icon-only button.

### 3.7 [HIGH] Custom template-picker dropdown keyboard-inaccessible
**Fix:** Replace with Radix `DropdownMenu` (deferred — complex).

### 3.8 [MEDIUM] × dismiss button in RulesPage has no accessible name
**Fix:** Add `aria-label={t('common.dismiss')}`.

### 3.9 [MEDIUM] Nested interactive elements inside role="button" cards
### 3.10 [MEDIUM] Border-radius inconsistency (rounded-[20px], rounded-2xl, rounded-lg)
**Fix:** Standardize to `rounded-2xl` for card surfaces.

### 3.11 [MEDIUM] Switch component 20×36px — below touch target
**Fix:** Increase to `h-6 w-11` (24×44px).

### 3.12 [MEDIUM] Admin table row action buttons ~26px touch targets
**Fix:** Increase to `h-9 w-9` / `p-2`.

### 3.13 [MEDIUM] ConfigCenterPage toolbar overflows on narrow viewports
**Fix:** Make toolbar `flex-wrap`.

### 3.14 [MEDIUM] TopologyPage three-column doesn't collapse on mobile
**Fix:** Change to `md:flex-row items-stretch`.

### 3.15 [MEDIUM] Select popovers inside mobile Sheet may conflict with focus trap
### 3.16 [LOW] Route progress bar animates width (see 2.3)
### 3.17 [LOW] useIsMobile re-renders (see 2.4)
### 3.18 [LOW] Loading→loaded no transition
### 3.19 [LOW] card-stagger only 8 children (see 2.7)
### 3.20 [LOW] Monaco editor fixed 480px height
**Fix:** Use `h-[60vh] min-h-[320px] md:h-[480px]`.

## 4. Code-Slimming Plan

### 4.1 Delete 7 production-dead exports + their tests
- `getTemplatesByCategory`, `getTemplateById` (configTemplates.ts)
- `formatBytes` (utils.ts)
- `DataTypeMap`, `DriverProtocols`, `TransportProtocols` (constants.ts)
- `THEME_LABELS` (themeStore.ts)

### 4.2 Delete 5 unused CSS classes + keyframes (~45 lines)
- `.shimmer`, `.popover-enter`, `.progress-indeterminate`, `.accordion-content`, `.focus-ring`

### 4.3 Delete ~17 dead i18n keys from both en.json and zh-CN.json
- 5 `nav.*` keys: dashboardEditor, groupSouthbound, groupControl, groupSystem, brandTagline
- 12 `connection.*` keys (except `connection.disconnect`)

### 4.4 Unify type duplicates
- `DataTypeString` → re-export `DataType` from config.ts
- `RuleStat.action` → import `RuleAction` from config.ts

### 4.5 Enable `noUnusedLocals`/`noUnusedParameters` in tsconfig.app.json
- Zero current cost (verified clean), prevents regression.

### 4.6 `any` → `unknown` at data boundary
- `DataPoint.value`, `WriteCommand.value`, `EngineStats.driver_stats`, `EngineStats.transport_stats`
