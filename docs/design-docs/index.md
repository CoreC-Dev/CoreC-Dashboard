# design-docs/ 索引

> 设计文档索引。写"为什么"和"边界"，不写"是什么"。

| 文档 | 职责 |
|---|---|
| `core-beliefs.md` | 第一性原则与操作原则——争议时回到这里裁决 |
| `architecture-decisions.md` | 架构决策记录（ADR）：框架判定、7 项人工决策 D1–D7、关键取舍 |
| `doc-gardening.md` | 文档防腐规则、必填节、园丁任务周期 |

## 写作约定
- 决策落盘格式：`ADR-<编号> <标题>` + 背景 + 决策 + 理由 + 影响 + 日期。
- 任何交互式决策确认后必须在此登记（core-beliefs #11）。
- 过时决策不删除，标 `状态：已取代 → ADR-<新编号>`。
